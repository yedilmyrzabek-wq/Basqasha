## 1. Главное в 10 пунктах

1. **Монетизация отодвигается.** С 01.02.2027 вход в YPP = 1 000 подписчиков + **8 000 часов** за 365 дней. Реальный RPM KZ ≈ **$0.1–0.5** (не $0.3–1). Memberships / Super Thanks / 500-подписочный уровень в KZ недоступны. Shorts — только воронка. → Главные деньги на 1-м году: спонсоры KZ и вторая аудиодорожка. *(monetization)*
2. **Наш пайплайн проходит политики YouTube**, если: нет «слайдшоу», есть вариативность формы, нет советов в 4 чувствительных областях (здоровье, финансы, право, **политика** — в брифе политика пропущена), хранится след человеческого вклада. Плоской анимации метка AI не нужна. *(monetization)*
3. **Новый риск — «Made for kids».** Маскот + образование → YouTube может классифицировать канал как детский (без персонализированной рекламы, комментариев, A/B-тестов). Решение: всегда «не для детей», тон и темы 13+. *(monetization, video_craft)*
4. **500–550 слов ≠ 4:00 для казахского.** Измеренный темп чтения казахского ≈ **107 слов/мин** → 500–550 слов ≈ 4:40–5:10. Бюджет слов надо вычислять из реального темпа голоса, количество сцен — из длины аудио. *(video_craft, kazakh_market)*
5. **ElevenLabs: казахский только в `eleven_v3` / `eleven_v4`.** Модель по умолчанию (Multilingual v2) и Flash/Turbo казахский **не поддерживают**. Для 12 видео/мес нужен **Creator $22** (Starter стоит $6 и его хватит на 4–6 видео). *(kazakh_market, tools_costs)*
6. **faster-whisper large-v3 `kk` — самый слабый вариант выравнивания** (WER 31–39%). Лучше: large-v3-turbo / казахский fine-tune (WER ~12–20%, локально, бесплатно), Gemini Transcribe или ElevenLabs Scribe (WER 5–10%). Выравнивать на уровне символов к утверждённому тексту. *(kazakh_market)*
7. **Шрифт Inter подходит** (все ә ғ қ ң ө ұ ү һ і проверены по cmap), обязательно с подмножеством `cyrillic-ext`. Многие модные шрифты казахский не покрывают. *(kazakh_market)*
8. **Стоимость:** ≈ **$1.57/видео сейчас → ≈ $2.14** после повышения цен Gemini (декабрь 2026 / январь 2027); 60% — картинки. Бюджет Google Cloud только предупреждает — реальный лимит ставится в AI Studio (spend cap). Supabase: подключение только через **Session pooler :5432** (прямой хост — только IPv6), автобэкапов нет → еженедельный `pg_dump` обязателен. *(tools_costs)*
9. **Конкуренция есть, ниша уже.** Казахские исторические каналы (SHKAMURO 503K, Тарих Марих 195K, qaztarih 43.6K) и русскоязычный Qalam History уже освещают этнографию. Свободная ниша — **качественная анимация** про науку, экономику, «как это устроено», привязанная к Казахстану. Русская дорожка выгоднее английской как второй язык. *(kazakh_market)*
10. **Бэклог: 44 темы** (22 A / 19 B / 3 C), формула балла, топ-10 на первый месяц: зима (P1) → самая большая страна без моря → сайгак → рождение тенге (к 15.11) → Медеу → родина яблок → соғым → Арал → экономика самсы → Темірқазық. *(topics_backlog)*

## 2. Правила, которые идут в систему (сводно)

### 2.1 Сценарий (шаг 4) → `/prompts`
- Бюджет слов: `target_words = round(wpm_voice × target_seconds / 60)`; по умолчанию `wpm_voice = 110` → 4:00 ≈ **440 слов** (±8%). После каждой загрузки mp3 `wpm_voice` пересчитывается (скользящее среднее). Счётчик длительности в UI — по этому значению. *(video_craft R1, kazakh_market R5)*
- Хук 0–15 с (≤ 28 слов): факт/цифра/парадокс с местом или годом → вопрос → открытая петля. Запрещены приветствия, «бұл видеода», название канала. Первая отдача до 0:30. *(video_craft R2–R3)*
- Шаблон из 8 битов на 240 с с бюджетом слов по битам; повторный хук каждые 45–60 с; предложения 6–12 слов (макс. 16); связки «бірақ / сондықтан». *(video_craft R4–R6)*
- Числа только словами; нормализация текста для TTS: без цифр, %, ₸, римских цифр; таблица сокращений; замена латинских «двойников» (ə→ә и т.п.). *(kazakh_market R2–R4)*
- Без советов (здоровье / финансы / право / политика) — LLM-проверка после написания; чувствительные темы (Ашаршылық, 1916, репрессии, жүз/ру, религия, границы) — ≥ 2 независимых источника на число + проверка нейтральности. *(monetization R2, kazakh_market R12, topics R10)*
- Вариативность: тип хука и структура не повторяются 2 видео подряд (`hook_type`, `structure_id` в `Project`); проверка близости брифа к прошлым видео (cos > 0.85 → предупреждение). *(monetization R3–R4)*
- Один подвопрос на видео, если источник длиннее 15 минут; заголовок отличается от источника. *(topics R7–R8)*

### 2.2 Раскадровка (шаг 6) → валидатор + промпт
- Сцен = `clamp(round(voice_seconds / 5.2), 40, 55)`; длина сцены 2.5 / 4.5–5.5 / 7.5 с. *(video_craft R7)*
- ≥ 2 визуальных события на сцену, пауза между событиями ≤ 3 с; хук — ≥ 4 сцены за 15 с. *(video_craft R8–R9, monetization R5)*
- 12–15 фонов по 2–4 раза, повтор — с другим фокусом / зумом; один punch-in на сцену. *(video_craft R10)*
- Плашки ≤ 5 слов **и** ≤ 24 символа; субтитры 2–7 слов, ≤ 42 символа в строке, ≤ 17 символов/с, одно ключевое слово (основа ≥ 3 букв). *(video_craft R11–R12)*

### 2.3 Аудио и рендер
- Голос −16 LUFS; **финальный микс −14 LUFS, true peak ≤ −1 dBTP**; музыка −18 dB под голосом; 12–20 SFX/мин. *(video_craft R13–R14)*
- Проверка шрифта на рендере: любой отсутствующий глиф = ошибка сборки. *(kazakh_market R8–R9)*

### 2.4 Картинки (шаг 7)
- `gemini-nano-banana-2.1`, 16:9, 2K, максимум 3 попытки на слот → потом `needs_manual`. *(tools_costs R3)*
- У ассетов есть `source` и `license`; флаги `is_photoreal`, `depicts_real_person` → автоматически вычисляют метку AI при публикации. *(monetization R6, R11)*

### 2.5 Озвучка и выравнивание (шаг 5)
- Сейчас вручную: «Копировать текст для ElevenLabs» (≤ 5 000 символов; подсказка «Модель: Eleven v4»), загрузка mp3. *(решение владельца, kazakh_market R1, tools_costs R10)*
- Выравнивание — настраиваемый движок (порядок предлагается в §4, вопрос 2); критерий: ≥ 90% слов привязаны, иначе следующий движок → silencedetect → флаг оператору. *(kazakh_market R6–R7)*

### 2.6 Метаданные (шаг 10)
- 5 заголовков ≤ 60 символов (хук в первых 40), ≥ 2 с числом, ≥ 2 с вопросом; описание ≤ 2 400 символов, главы с 00:00, источники, ≤ 3 хэштегов; превью — текст ≤ 3 слов кодом, 3 варианта для A/B. Чек-лист публикации: «не для детей», метка AI по флагам, «Paid promotion» при спонсоре. *(video_craft R15–R17, monetization R8, R14)*

### 2.7 Инфраструктура, деньги, ключи
- Модели по умолчанию (проверяются через `models.list()` при старте): текст `gemini-3.8-flash`, сценарий `gemini-4-argon` (fallback flash), дешёвая `gemini-3.5-flash-lite`, картинки `gemini-nano-banana-2.1`, embeddings `gemini-embedding-2` (768). Запрещены выключенные модели. *(tools_costs R1–R2)*
- Бюджет: предупреждение > $2.50 на проект, жёсткая остановка > $4.00; месяц — spend cap $40 в AI Studio, приложение останавливается при $35. Цены в журнале расходов — таблица с `effective_from` (повышения цен уже учтены). *(tools_costs R4–R9)*
- Supabase: Session pooler URL, `pool_pre_ping`, баннер «проект мог уснуть», `SELECT 1` раз в день, еженедельный `pg_dump` в `data/backups/` (хранить 8). *(tools_costs R11–R12)*
- yt-dlp с `--js-runtimes node`, обработка блокировок, ручная вставка транскрипта — обязательный путь. *(tools_costs R13)*
- `claude -p` — расходы $0 в журнале, при лимите автоматический переход на Gemini. *(tools_costs R15)*
- Язык: enum `kk`, `ru`, `en`; поле `script = Cyrl` в проекте. *(kazakh_market R10, R15)*

### 2.8 Выбор тем
- Формула балла `2·D + 3·K + 1.5·V + 1.5·F − 3·R` (макс. 40); первые 30 дней — только A с D ≥ 3 и R ≤ 1; ротация категорий; «как предки обходились без X» — не чаще раза в 14 дней; сезонный календарь. *(topics R1–R12)*
- Темп: 2–4 длинных видео в неделю (не больше 4), ≤ 3 Shorts на видео. *(monetization R9–R10)*
