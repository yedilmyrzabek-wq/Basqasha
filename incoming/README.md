# incoming/ — сюда владелец кладёт свои материалы

Кладите файлы как есть, в любом формате. Claude разберёт их и разложит по `library/`
(с обновлением `poses.json` / `sfx.json`). Эта папка — только «входящие».

| Папка | Что класть | Формат |
|---|---|---|
| `character/` | эталон персонажа (он же логотип): спереди, сбоку, 3/4, лист-референс | PNG/JPG, любое |
| `poses/` | позы персонажа | лучше PNG с прозрачным фоном, по одной позе на файл, имя = название позы (`think.png`, `shock.png`…). Можно лист поз на зелёном фоне #00FF00 |
| `motion/` | движения / анимации персонажа | GIF, MP4/WebM (желательно с прозрачностью или на зелёном фоне), PNG-секвенции, Lottie (.json) |
| `style/` | примеры фонов в вашем стиле, палитра, шрифты | PNG/JPG, .ttf/.otf, текст с HEX-цветами |
| `sfx/` | короткие звуки (whoosh, pop, ding…) | WAV/MP3, имя = назначение |
| `music/` | музыкальная подложка | WAV/MP3 (только с лицензией) |
